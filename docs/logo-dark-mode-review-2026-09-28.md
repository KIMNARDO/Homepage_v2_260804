# 다크 모드 로고 가장자리 수정 검토

사용자가 지적한 상단 로고의 불규칙한 흰 테두리를 로컬 미리보기에서 수정했다. 운영 배포와 Git 커밋·푸시는 실행하지 않았다.

## 원인과 수정

기존 `images/papsnet-logo-transparent.png`는 124×61px PNG다. 투명 배경이어도 로고 가장자리에는 흰색 매트가 남아 있었다. 실제 픽셀 검사에서 알파가 0보다 크고 RGB가 모두 200을 넘는 밝은 픽셀 1,322개를 확인했다. 수정 전 다크 모드의 CSS 필터는 `none`이었으며 흰 윤곽선은 그림자 효과가 아니라 이미지에서 나왔다.

원본 이미지의 파란색 성분으로 마스크를 만드는 SVG 표시 필터를 적용했다. 흰색 잔여 픽셀을 제외하고 밝은 블루 단색으로 표시하며 원본 알파를 함께 사용한다. 기존 심벌과 글자 배치를 사용하고 흰색 배경 상자를 추가하지 않는다. 원본 파일을 재저장하거나 변경하지 않았다.

- 적용: 다크 모드의 스크롤된 내비게이션과 모바일 메뉴.
- 밝은 테마 및 페이지 최상단의 밝은 내비게이션: 원본 로고 표시.
- 구현: `index.html`의 숨겨진 필터 정의와 두 로고 클래스, `amphora-plm.css`의 테마·메뉴 상태별 필터 선택.
- 필터는 현재 파란색 로고에 맞춘 처리다. 추후 깨끗한 SVG 또는 고해상도 투명 원본으로 교체하면 이 필터도 함께 정리한다.

## 검증

- 데스크톱의 밝은·어두운 메뉴 및 페이지 상단 상태를 확인했다.
- 390px 모바일 상단과 펼친 메뉴에서 흰 테두리가 제거된 로고를 확인했다.
- 원본 PNG SHA-256 유지: `FA8902F3D2565E45AE88D37CDB8C3A76B2C1D0F42BB15D92D85B8B85BE169201`.
- Vite 빌드 통과. 빌드 HTML의 필터 ID 및 두 로고 클래스 유지 확인.
- 비교 화면: `output/logo-review/dark-before.png`, `dark-after.png`, `light-after.png`, `dark-top.png`, `dark-mobile-menu.png`.

로고의 투명 배경 여부뿐 아니라 밝은·어두운 배경에서 가장자리의 흰색 매트까지 확인해야 한다.
