사전원가 · ECMS

견적 단계부터
일관된 기준의 원가 산출

프로젝트를 등록하고 공정별 설비·자재·직무를 설정한 뒤 TactTime을 입력하면 재료비·노무비·감가상각비가 자동 산출됩니다. 공정별 수율 조건을 비교해 목표 수익률에 맞는 기준 판가를 검토합니다.

  • 재료비·노무비·감가상각비 자동 산출
  • TactTime 기반 시간당 생산량·임율 자동 계산
  • 조건별 수율 비교와 기준 판가 산출
  • 유사모델 불러오기로 신규 견적 빠른 구성
사후원가 · ICMS

SAP와 원소재 시세,
가격 변동까지 자동 반영

매일 SAP에서 협력사·품목·매입단가·사급단가를 자동 동기화하고, 한국수입협회·LME 시세 데이터를 연동해 원소재 공시단가를 자동 반영합니다. 매입단가 변경 시 가격합의서가 자동 생성되어 협력사에게 이메일·알림톡으로 발송됩니다.

  • SAP 협력사·판매처·품목 매일 자동 동기화
  • 원소재 공시단가 자동 업데이트 (철강재·비철금속)
  • 가격변경 합의서 자동 생성 + 전자서명
  • 협력사 승인·반려·재전송 워크플로
통합 대시보드

사전 vs 사후,
원가 예측 정확도를 높여갑니다

견적 시점 예측 원가와 실제 집행된 실적 원가를 항목별로 자동 비교합니다. 수율·원가요소별 편차를 시각화하고 개선 포인트를 도출해 다음 견적의 정확도를 높이는 피드백 루프를 만듭니다. 부서별(금형·설비·외주·노무·운반) 리비전 관리로 변경 책임도 명확해집니다.

  • 사전 vs 사후 원가 항목별 편차 분석
  • 수율·원가요소별 차이 요인 도출
  • 부서별 리비전 이력 관리 (금형·설비·외주·노무)
  • MES·ERP 실적 데이터 자동 집계 (SAP 등)

  • SAP 협력사 · 판매처 · 품목 자동 동기화

  • 협력사 품목 엑셀 일괄 업로드 · 유효성 검사
