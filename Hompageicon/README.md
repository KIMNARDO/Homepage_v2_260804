# Hompageicon — 홈페이지 리디자인 에셋

> 목적: 카드/컴포넌트 리디자인(구글 Stitch)을 위한 참고 자료 모음.
> Stitch에서 리디자인한 결과(이미지/HTML/CSS/스펙)를 주시면 사이트에 정확히 반영합니다.

## ⚠️ 먼저 — 아이콘은 "파일"이 아니라 "폰트"입니다
현재 홈페이지의 모든 아이콘은 **Material Symbols Rounded**(구글 아이콘 *폰트*)로,
`<span class="material-symbols-rounded">draw</span>` 처럼 **글리프(ligature)** 로 렌더링됩니다.
→ 원래 "복사해 넣을 이미지 파일"이 존재하지 않습니다. 대신:
- `icons-inventory.md` 에 **사용된 모든 아이콘 이름 · 사용 위치 · 다운로드 링크**를 정리했습니다.
- SVG 파일이 필요하면 말씀해 주세요. 카드용 아이콘들을 SVG로 받아 이 폴더(`svg/`)에 넣어드리겠습니다.

## 💡 솔직한 추천
지금까지 마음에 안 들었던 건 **아이콘 자체가 아니라 "카드 컴포넌트의 구성/스타일"**(비율·아이콘 컨테이너·여백·색)이었습니다.
Material Symbols 아이콘은 그 자체로 깔끔·일관·전문적입니다(구글·대형 SaaS에서 광범위 사용).

그래서 Stitch에서는:
1. **카드 컴포넌트(프레임 · 아이콘 컨테이너 · 레이아웃 · 간격 · 색)** 를 리디자인 — 여기가 핵심.
2. **글리프는 Material Symbols 유지**(또는 다른 Material 아이콘으로 교체) — 다크모드·유지보수·일관성에 유리(커스텀 SVG 40여 개를 따로 관리할 필요 없음).
3. 정말 풀커스텀 아이콘을 원하면 그것도 가능 — 단 폰트 → 커스텀 SVG 전면 교체라 관리 부담이 커집니다. 어느 쪽이든 반영해 드립니다.

## 📁 폴더 구성
- `README.md` — 이 문서
- `icons-inventory.md` — 사용 아이콘 전체 목록(이름 · 위치 · 다운로드 링크)
- `components-to-redesign.md` — 리디자인 대상 컴포넌트 스펙(마크업 · 현재 스타일 · 리디자인 포인트 · 디자인 토큰)
- `svg/` — 카드용 아이콘 SVG **27종** (filled, Material Symbols Rounded · 24px)
- `svg/ui/` — UI·장식 아이콘 SVG **17종**

> 시각 참고는 라이브 사이트(`localhost:5173`)에서 직접 캡처해 Stitch에 함께 첨부하면 정확도가 올라갑니다.
> (자동화 브라우저 스크린샷은 원격 기기에 저장되어 이 PC 폴더로 자동 복사가 되지 않습니다.)

## 🔁 핸드오프 방법
Stitch 결과를 주시는 형태에 따라:
- **이미지 시안** → 제가 보고 HTML/CSS로 정확히 구현
- **HTML/CSS** → 디자인 토큰·구조에 맞춰 통합
- **스펙(치수·색·폰트)** → 그대로 반영
